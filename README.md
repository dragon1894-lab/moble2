# moble2 조별 프로젝트 안내

## 1. GitHub 프로젝트 업로드 방법

### 1-1. 자기 브랜치 선택

1. [moble2 저장소](https://github.com/dragon1894-lab/moble2)에 접속합니다.
2. 파일 목록 위쪽의 브랜치 버튼을 누릅니다.
3. 반드시 **자기 이름 브랜치**를 선택합니다.
4. `main`과 `test` 브랜치에는 직접 올리지 않습니다.
5. 파일 목록 위쪽의 **+ 버튼 → Upload files**를 누릅니다.
6. 큰 흰색 업로드 공간에 프로젝트 파일을 드래그합니다.

### 1-2. 올려야 하는 파일

프로젝트 폴더에 존재하는 아래 파일을 모두 올립니다.

- `.sln`: Visual Studio에서 전체 프로젝트를 여는 파일
- `.csproj`: 프로젝트 설정 파일
- 모든 `.cs`: 실제 프로그램 코드
- 모든 `.Designer.cs`: 폼 화면과 버튼의 배치 정보
- 모든 `.resx`: 폼 이미지와 리소스 정보
- 직접 사용한 이미지, 아이콘, 리소스 폴더

WinForms 폼은 보통 다음 세 파일이 한 세트입니다.

```text
Form1.cs
Form1.Designer.cs
Form1.resx
```

`Designer.cs`나 `.resx`가 없는 프로젝트는 새로 만들 필요가 없습니다. 현재 프로젝트에 존재하는 파일만 빠짐없이 올리면 됩니다.

### 1-3. 올리지 않는 항목

- `.vs` 폴더
- `bin` 폴더
- `obj` 폴더
- `.csproj.user` 파일

위 항목들은 Visual Studio가 자동으로 다시 생성하는 임시 파일입니다.

### 1-4. 작업 제목 작성 및 업로드 완료

1. 파일을 올린 후 화면 아래의 **Commit changes** 영역으로 이동합니다.
2. `Add files via upload`이라고 표시된 첫 번째 한 줄 입력칸에 작업 제목을 작성합니다.
3. 제목 예: `로그인 화면 코드 추가`, `게임 기능 추가`, `폼 디자인 완성`, `오류 수정`
4. 그 아래 큰 입력칸은 자세한 설명란이며 비워도 됩니다.
5. **Commit directly to 자기 이름 branch**가 선택됐는지 확인합니다.
6. 초록색 **Commit changes** 버튼을 누릅니다.
7. 자기 브랜치에 파일이 표시되면 완료입니다.

## 2. 다른 사람 프로젝트 다운로드하기

1. moble2 저장소에 접속합니다.
2. 파일 목록 위쪽의 브랜치 버튼을 누릅니다.
3. 다운로드할 사람의 이름 브랜치를 선택합니다.
4. 초록색 **Code** 버튼을 누릅니다.
5. 팝업 위쪽에서 **Local**을 선택합니다.
6. **Download ZIP**을 누릅니다.
7. 다운로드된 ZIP 파일의 압축을 풉니다.

---

## 3. Visual Studio 2022에서 실행하기

1. 압축을 푼 폴더를 엽니다.
2. 폴더 안의 `.sln` 파일을 더블클릭합니다.
3. Visual Studio 2022가 열릴 때까지 기다립니다.
4. 보안 경고가 나오면 팀 코드가 맞는지 확인한 후 진행합니다.
5. 상단의 초록색 실행 버튼 또는 `F5`를 누릅니다.
6. 오류 없이 프로그램 창이 나오면 정상입니다.

`.sln`이 바로 열리지 않으면 **파일 → 열기 → 프로젝트/솔루션 → .sln 파일 선택** 순서로 엽니다.

## 4. 잘못 올린 파일 삭제하기

1. moble2 저장소에 접속합니다.
2. 반드시 **자기 이름 브랜치**를 선택합니다.
3. 파일 목록에서 삭제할 파일 이름을 눌러 파일 내용을 엽니다.
4. 파일 내용 오른쪽 위의 **점 3개(…)** 또는 연필 버튼 옆의 메뉴를 누릅니다.
5. **Delete file**을 선택합니다.
6. 아래 **Commit changes** 영역으로 이동합니다.
7. 첫 번째 입력칸에 `잘못 올린 파일 삭제`처럼 삭제 이유를 작성합니다.
8. **Commit directly to 자기 이름 branch**가 선택됐는지 확인합니다.
9. 초록색 **Commit changes**를 누릅니다.
10. 파일 목록에서 해당 파일이 사라졌으면 삭제 완료입니다.

### 폴더를 잘못 올렸을 때

GitHub 웹에서는 폴더만 한 번에 삭제하기 어렵습니다. 폴더 안의 파일을 하나씩 열어 **Delete file → Commit changes**로 모두 삭제하면 빈 폴더는 자동으로 사라집니다.

### 삭제할 때 주의사항

- `main`과 `test`의 파일은 직접 삭제하지 않습니다.
- `.sln`, `.csproj`, `.cs`, `.Designer.cs`, `.resx`는 실행에 필요할 수 있으므로 함부로 삭제하지 않습니다.
- 잘못 올린 `.vs`, `bin`, `obj`, `.csproj.user`는 삭제해도 됩니다.
- 다른 팀원이 만든 파일은 확인 없이 삭제하지 않습니다.

---

## 5. 팀 작업 규칙

1. 각자 자기 이름 브랜치에만 코드를 올립니다.
2. `test`와 `main`에는 직접 올리지 않습니다.
3. 개인 브랜치의 코드를 먼저 `test`에 합쳐 실행합니다.
4. 모든 기능이 정상 작동하면 최종본만 `main`에 반영합니다.
5. 같은 파일을 여러 명이 동시에 수정하지 않도록 역할을 나눕니다.
